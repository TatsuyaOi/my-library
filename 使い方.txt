My Library — ★仮置き保管庫を使う運用（2026-09-05）

1. my-library/★仮置き保管庫 にHTML・画像・Markdown・TXTを保存します。
2. my-libraryを開いたCodexへ次のように伝えます。

「★仮置き保管庫の未処理資料を、AGENTS.mdに従って整理してください。
 原本と既存デザインを維持し、必要な閲覧HTML・meta.json・索引を作成して、
 検証後にPRまで作成してください。機密・判断不能な資料は保留し、マージしないでください。」

3. PRの差分と検証結果を確認し、自分でマージします。
4. GitHub Actionsのrebuild / deploy成功後にGitHub Pagesを確認します。

初回: Settings → Pages → Source を GitHub Actions に設定します。
詳細: docs/inbox-workflow.md と 導入手順.md を参照してください。

重要:
- このリポジトリは公開用途です。仕事の機密・住所・予約番号・認証情報は公開しないでください。
- Inbox内容は既定で.gitignore対象。Cloud Codexは未pushのローカルファイルを読めません。
- Cloud利用時は公開可能な原本だけを明示的に作業ブランチへ追加します。
- 「ファイルを置くだけでAIが自動起動」ではありません。Codexへの整理指示が必要です。
- 原本は削除しません。処理済みとして識別します。
- 旧手順の「12_簿記」「LIBRARY_ITEMSを手編集」は使いません。簿記は22_簿記です。
- library-all.json / 各カテゴリlibrary.json / 各カテゴリindex.htmlは自動生成物です。
- PDF・Office・ZIP・SVG・動画はこの取り込みスクリプトでは変換しません。
