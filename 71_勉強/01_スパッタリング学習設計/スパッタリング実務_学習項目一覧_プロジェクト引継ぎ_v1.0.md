# スパッタリング実務
## 学習項目一覧・プロジェクト引継ぎ設計書 v1.0

> **目標：装置の設定値を覚えるだけでなく、「なぜその条件でその膜ができるか」を説明し、比較実験・評価・不具合解析・量産管理までつなげられるようになる。**

この文書は、学習項目の一覧と、それを教科書・講義・演習へ展開するための設計書である。本文そのものは教科書の完成稿ではない。別プロジェクトへこのファイルを添付し、末尾の「引継ぎ用の依頼文」を使用すれば、章単位・分野単位で学習資料の制作を開始できる。

学習項目の選定・章分け・優先順位は、本件に合わせたカリキュラム案であり、公的な資格基準ではない。技術的な参考資料は末尾に整理した。出典の材料・装置・試験条件と、説明対象の材料・装置を混同しない。

### まず持つべき5つの視点

**装置の設定 → 実際のプロセス状態 → 膜・界面の構造 → 物性 → 製品性能**を、別々の段階として扱う。

例えば「出力を上げた」は設定の変更、「成膜速度が上がった」は観測された状態、「緻密になった」は分析で確かめる構造の変化、「硬くなった」は物性、「摺動の傷が見えにくくなった」は製品・試験性能である。途中を測らずに、これらを同一視しない。

## 1. 学習の全体マップ

### 優先度の定義

| P1 | **共通必須。** 原理、計測、比較実験、再現性、工程管理の基盤。 |
| P2 | **今回の重点分野。** 反応性・R2R・樹脂基材・光学膜では優先して習得する。 |

## 2. 詳細学習項目：36章・216項目

各項目は「説明を1段落で終える用語集」ではなく、独立した小節へ展開できる単位としている。例えば19.4だけで、固定条件の違いを扱う学習資料を制作できる。

### A. 導入・安全・基礎

#### 第01章　スパッタリングの全体像と仕事の流れ

**優先度：P1｜難易度：入門｜主な前提：なし**

**到達目標：** 要求仕様から成膜・評価・原因解析・量産管理まで、担当業務の位置づけを説明できる。

- **01.1 薄膜と表面機能：** バルク材料との違い、膜厚・界面・基材の重要性、光学膜・電極膜・保護膜の用途を整理する。
- **01.2 PVD・CVD・ALDの位置づけ：** 蒸着、スパッタリング、化学気相成長、原子層堆積を、原理・温度・形状追従性・速度の観点で比較する。
- **01.3 材料から製品までの流れ：** 基材準備、前処理、排気、予備放電、成膜、後処理、検査、出荷判定のつながりを学ぶ。
- **01.4 装置形式：** バッチ、インライン、R2Rの違いと、研究装置と量産装置で異なる制約を把握する。
- **01.5 職務ごとの責任範囲：** 装置運転、条件設計、分析、品質保証、設備保全の役割と、変更承認・相談の境界を区別する。
- **01.6 仕様と評価指標：** 膜厚、光学特性、抵抗、密着、摺動、屈曲、均一性、生産性を要求仕様へ結びつける。

**確認課題・成果物：** 想定製品を1つ選び、工程、要求仕様、評価方法、担当部門を1枚の表にする。

#### 第02章　安全・作業標準・設備を止める判断

**優先度：P0｜難易度：入門｜主な前提：なし**

**到達目標：** 危険源と停止・報告基準を把握し、教育・承認された範囲で作業できる。

- **02.1 電気・蓄積エネルギー：** 高電圧、RF、コンデンサの残留電荷、接地、保守時のエネルギー隔離について学ぶ。
- **02.2 真空・圧力・ガス：** 真空容器、窓、ガス配管、酸欠、酸素による燃焼助長、ガス種別の危険を確認する。
- **02.3 冷却水と温度：** 流量不足、水漏れ、ターゲット過熱、冷却回路の役割と異常停止条件を学ぶ。
- **02.4 R2Rの機械的危険：** 巻き込まれ、挟まれ、張力がかかったフィルム、重量ロールの取扱いを学ぶ。
- **02.5 材料・清掃・廃棄：** ターゲット、堆積物、粉じん、洗浄剤についてSDS、保護具、回収・廃棄ルールを確認する。
- **02.6 インターロックと作業許可：** 安全機構を無効化しない原則、異常時の連絡、保守担当への引継ぎ、再起動承認を学ぶ。

**確認課題・成果物：** 実機の取扱説明書と社内手順から、禁止操作・停止条件・連絡先を整理する。教材だけで作業資格を判断しない。

#### 第03章　物理・化学・数学と単位の基礎

**優先度：P1｜難易度：入門〜基礎｜主な前提：なし**

**到達目標：** 装置設定、膜厚、熱、応力の計算を、単位の整合性を確認しながら扱える。

- **03.1 単位と桁：** Pa、Torr、mbar、sccm、W、W/cm²、eV、nm、N/m、MPaの意味と換算を学ぶ。
- **03.2 物質量と組成：** 原子比、質量比、化学量論組成、酸化数、酸素欠損、結合と電子状態の基礎を整理する。
- **03.3 電気・磁気：** 電位、電圧、電流、電力、インピーダンス、電場・磁場、荷電粒子への力を復習する。
- **03.4 運動と熱：** 運動エネルギー、運動量、温度、熱量、熱流束、熱容量を区別する。
- **03.5 力学と光学：** 応力・ひずみ・弾性率、屈折率・吸収・反射・干渉の基本量を整理する。
- **03.6 実務計算：** 比例、対数、微分・積分の意味、平均・分散、不確かさ、次元解析を使えるようにする。

**確認課題・成果物：** 出力密度、単位幅張力、滞在時間、膜厚の4種類の計算を、単位付きで説明する。

### B. 真空・ガス

#### 第04章　真空中の気体と粒子輸送

**優先度：P1｜難易度：基礎〜中級｜主な前提：03**

**到達目標：** 圧力と輸送距離が、粒子の到達状態や汚染にどう関係するか説明できる。

- **04.1 到達圧力と成膜圧力：** 排気後の圧力とガス導入・放電中の圧力を区別する。
- **04.2 全圧・分圧・組成：** 全圧と各ガス分圧、流量比との違い、測定位置による差を学ぶ。
- **04.3 平均自由行程：** 圧力・温度・衝突断面積との関係と、熱平衡気体の式を高速粒子へ使う際の限界を学ぶ。
- **04.4 散乱とエネルギー損失：** Si、Nbなどの粒子とAr等の衝突、質量差、角度変化、エネルギー分布を扱う。
- **04.5 流れの領域：** 粘性流、遷移流、分子流、クヌーセン数、配管内と成膜空間の違いを学ぶ。
- **04.6 表面への入射と滞留：** 分子入射頻度、吸着、脱離、付着確率、表面被覆と清浄度の関係を学ぶ。

**確認課題・成果物：** 圧力を変えたときに、粒子輸送・放電・酸素反応・ガス排出の何が同時に変わるか分類する。

関連する導入資料：R1。材料・装置の適用範囲は末尾を参照。

#### 第05章　排気系・真空計・リーク診断

**優先度：P1｜難易度：基礎〜中級｜主な前提：02〜04**

**到達目標：** 圧力の異常を、ガス負荷・排気能力・測定誤差に分けて考えられる。

- **05.1 真空ポンプ：** ドライ、ロータリー、ターボ分子、クライオ、拡散ポンプの役割と適用範囲を整理する。
- **05.2 実効排気速度：** ポンプ公称値、配管コンダクタンス、スロットルバルブ、圧力制御の関係を学ぶ。
- **05.3 真空計の原理：** 隔膜、ピラニ、電離真空計などの測定原理、圧力範囲、ガス種依存性を区別する。
- **05.4 排気曲線：** 排気開始からの圧力推移、リーク、脱ガス、仮想リーク、ポンプ性能劣化を考える。
- **05.5 残留ガス分析：** 水分、酸素、窒素、炭化水素などの見方と、質量ピークの重なりを学ぶ。
- **05.6 リーク検査と校正：** ヘリウムリーク検査、計器のゼロ点・校正、測定ポート位置、履歴管理を学ぶ。

**確認課題・成果物：** 排気不良の原因候補を、確認項目と担当者を含む切り分け表にする。

関連する導入資料：R1、R6。材料・装置の適用範囲は末尾を参照。

#### 第06章　ガス供給・残留水分・空間分布

**優先度：P1｜難易度：基礎〜中級｜主な前提：04、05**

**到達目標：** ガス流量設定と、実際の成膜位置のガス環境を区別できる。

- **06.1 MFCと流量：** マスフローコントローラ、校正ガス、標準状態の定義、応答性、流量レンジを学ぶ。
- **06.2 Ar・O₂・N₂の役割：** 放電維持、酸化・窒化、混合ガスによるプラズマ状態の変化を整理する。
- **06.3 供給と排気の収支：** ガス導入、排気、ターゲット・壁・基材での反応消費、滞留時間を学ぶ。
- **06.4 ガス純度と水分：** ボンベ・配管・シール・基材・HC・チャンバー壁からの汚染源を整理する。
- **06.5 幅方向ガス分布：** 導入位置、多点供給、排気位置、局所消費による幅方向の不均一を学ぶ。
- **06.6 ゾーン間干渉：** 多層R2Rでのガス回り込み、差動排気、隣接カソード・前処理との干渉を学ぶ。

**確認課題・成果物：** O₂流量が同じでも膜組成が変わる仮説を、供給・消費・排気・残留ガスに分ける。

関連する導入資料：R3、R6。材料・装置の適用範囲は末尾を参照。

### C. プラズマ・スパッタ原理

#### 第07章　プラズマ・放電・シース

**優先度：P1｜難易度：基礎〜中級｜主な前提：03、04**

**到達目標：** 電子、イオン、中性種の役割と、ターゲット側・基材側の電位差を説明できる。

- **07.1 プラズマを構成する粒子：** 電子、正イオン、負イオン、中性原子、分子、ラジカルを区別する。
- **07.2 電離・励起・解離：** 電子衝突で起こる反応と、プラズマ発光が何を反映するかを学ぶ。
- **07.3 放電の点火と維持：** 点火条件と定常維持条件の違い、圧力・磁場・電源の役割を学ぶ。
- **07.4 シースと電位：** プラズマ電位、浮遊電位、電極電位、シースによる加速を学ぶ。
- **07.5 二次電子放出：** イオン衝撃とターゲット表面状態が、電子供給と放電に関与する仕組みを学ぶ。
- **07.6 プラズマ診断：** OES、電流・電圧波形、プローブ、質量・エネルギー分析の測定対象と限界を整理する。

**確認課題・成果物：** ターゲットへのイオン衝撃と、成膜面への粒子入射を別々に説明する。

関連する導入資料：R3、R7。材料・装置の適用範囲は末尾を参照。

#### 第08章　スパッタ現象と飛び出した粒子の挙動

**優先度：P1｜難易度：基礎〜中級｜主な前提：04、07**

**到達目標：** ターゲットからの放出、気相輸送、基材への到達を区別できる。

- **08.1 衝突カスケード：** 入射イオンの運動量・エネルギーが固体へ渡り、原子が放出される過程を学ぶ。
- **08.2 スパッタ収率：** イオン種、エネルギー、入射角、材料、表面化合物が収率へ与える影響を学ぶ。
- **08.3 放出粒子の分布：** 放出角度・エネルギーの分布、中性粒子とイオン化粒子、組成移送を学ぶ。
- **08.4 高速粒子：** 反跳中性粒子、酸素負イオンなど、膜成長や基材損傷に関わる粒子を学ぶ。
- **08.5 輸送距離と遮蔽：** ターゲット・基板間距離、圧力、マスク、視線方向と散乱の関係を学ぶ。
- **08.6 付着と再スパッタ：** 到達量と正味堆積量の違い、付着確率、再放出、選択的な除去を学ぶ。

**確認課題・成果物：** 放電出力、ターゲットへのイオンエネルギー、基材に届く原子のエネルギーを区別する。

関連する導入資料：R1、R2。材料・装置の適用範囲は末尾を参照。

#### 第09章　マグネトロン・磁場・成膜配置

**優先度：P1｜難易度：基礎〜中級｜主な前提：07、08**

**到達目標：** カソードと周辺構造が、放電・均一性・基材への入射を変える理由を説明できる。

- **09.1 電子の閉じ込め：** 電場と磁場による電子運動、電離効率、低圧放電との関係を学ぶ。
- **09.2 平面型と回転型：** 平面ターゲット、円筒回転ターゲット、使用効率と分布の違いを整理する。
- **09.3 平衡・非平衡磁場：** 磁力線構成と基材近傍プラズマ、イオン入射の関係を学ぶ。
- **09.4 エロージョン形状：** レーストラック、侵食深さ、ターゲット寿命に伴う磁場変化を学ぶ。

- **36.3 破壊機構の仮説：** 表面摩耗、割れ、剥離、下地変形、移着、表面処理の消耗を区別する。
- **36.4 重点5因子の設計：** 出力、圧力、冷却水温、速度、張力の主効果・交互作用・交絡を整理する。
- **36.5 性能と原因の両評価：** 摺動と光学に加え、組成・密度・応力・粗さ・温度を必要に応じて組み合わせる。
- **36.6 条件窓と引継ぎ：** 最良1点ではなく許容範囲を示し、別日・別ロットの確認と管理項目を提案する。

**確認課題・成果物：** 試験計画書、評価計画書、条件台帳、結果判定表、量産移管時の注意の5点を作成する。


## 3. 重点5因子を学ぶときの具体的な問い

「上げると良い／下げると良い」の暗記ではなく、**何が直接変わり、何が連動し、何を測れば確認できるか**を学ぶ。

### 3.1 放電出力：主に第10・14・18・19章

**理解すべき中心：** 電気的な入力、ターゲットからの供給量、成長面への入射量、熱負荷、反応状態は同じ量ではない。

| 学ぶ問い | 確認・学習する内容 |
|---|---|
| 出力を上げると電圧と電流はどう変わるか | 電源制御モード、波形、ターゲット材料・酸化状態。 |
| 出力と成膜速度は比例するか | 運転領域内の実測関係、ポイズニング、再スパッタ、輸送損失。 |
| 原子の数と1個あたりエネルギーは同時に増えるか | 到達フラックス、エネルギー分布、イオン／原子比を分ける。 |
| O₂流量一定で出力を変えると何が変わるか | 金属供給、ターゲット被覆、酸素消費、膜組成。 |
| 厚さを合わせれば出力の効果だけになるか | 厚さ補正に伴う速度・時間・前処理ドーズ・温度変化を確認する。 |

**最低限の記録候補：** 電源方式、制御モード、平均出力、可能なら波形情報、V/I、アーク統計、成膜速度、膜厚、O₂関連状態、実フィルム温度。

### 3.2 チャンバーの成膜圧力：主に第04〜06・08・19章

**理解すべき中心：** 「圧力」は粒子輸送だけでなく、放電と反応にも関わる。圧力計の値は、必ずしも成膜位置の全情報ではない。[R1、R3]

| 学ぶ問い | 確認・学習する内容 |
|---|---|
| 全圧を変えた方法は何か | Ar流量変更、O₂流量変更、スロットル変更を区別する。 |
| 全圧一定でO₂分圧は同じか | 分圧測定と反応消費。流量比を分圧比と同一視しない。 |
| 低圧で粒子輸送はどう変わるか | 距離、衝突断面積、質量差、方向・エネルギー分布。 |
| 低圧化が必ず緻密化・摺動改善になるか | 放電安定性、反応不足、高速粒子損傷、応力、基材との組合せ。 |
| 高圧時の出力増加は何を補えるか | 到達量・加熱・反応状態の変化を測り、単純な補償とは考えない。 |

**最低限の記録候補：** 全圧、圧力計・設置位置、Ar/O₂流量、可能な分圧、バルブ位置、排気・ガス導入構成、成膜距離、V/I、膜厚・組成。

### 3.3 冷却水温：主に第20章

**理解すべき中心：** 水温、ドラム温度、実フィルム温度を区別する。水側の熱収支と、フィルムからドラムへ熱が渡る過程を別々に見る。[R4、R5]

| 学ぶ問い | 確認・学習する内容 |
|---|---|
| 水温を下げると表面温度は何℃下がるか | 装置・接触・入熱・滞在時間を含む実測または検証済みモデル。一般値を断定しない。 |
| 流量と温度差から何が分かるか | 冷却回路が回収した熱。フィルムだけの熱とは限らない。 |
| 接触が悪いとどうなるか | 熱抵抗、微小すき間、張力、ドラム表面、局所温度差。 |
| 基材が透明なとき温度をどう測るか | 放射率・透過・背景反射・プラズマ発光の影響と、測定の校正。 |
| 冷却を強めると膜質が悪化するか | 自動的には断定しない。成長の熱的・非熱的寄与と実温度差を確認する。 |

**最低限の記録候補：** 冷却水入口・出口温度、流量、ドラム温度、フィルム温度の位置・方法・不確かさ、速度、張力、出力、熱的な安定化時間。

### 3.4 ライン速度：主に第21章

**理解すべき中心：** 速度は膜厚だけでなく、前処理・加熱・冷却・反応に使える時間を変える。一定膜厚比較と固定出力比較は異なる実験である。

| 比較の種類 | 学ぶべき解釈 |
|---|---|
| 出力固定で速度を変える | 膜厚と照射履歴が変わる、工程全体の速度影響を調べる。 |
| 速度に合わせて出力を変え、膜厚を合わせる | 同一膜厚での工程条件比較。出力・反応状態・熱負荷も変わるため「純粋な速度効果」ではない。 |
| パス数で膜厚を合わせる | 各パスの成長、途中冷却、再照射、界面・表面履歴が変わる。 |
| スリット幅やゾーン長で補正する | 入射角・空間分布・滞在時間が変わる可能性も確認する。 |

**最低限の記録候補：** 実速度、加減速区間、パス数、ゾーン長、膜厚、各カソード出力、前処理条件、温度履歴、採取位置。

### 3.5 搬送張力：主に第21・22章

**理解すべき中心：** 張力は接触・冷却と基材ひずみの両方に関わる。設定張力、測定位置の張力、幅方向分布は区別する。[R4、R5]

| 学ぶ問い | 確認・学習する内容 |
|---|---|
| NとN/mはどう違うか | 幅で規格化した張力、同じ値を異なる幅・厚さに使う問題。 |
| 張力を上げると必ずよく冷えるか | 接触の改善、飽和、表面形状、局所浮き、温度依存性を実測する。 |
| 同じ張力で基材の伸びは同じか | 厚さ、幅、温度、粘弾性、HCと無機膜の荷重分担。 |
| 伸ばした基材に成膜してから解放するとどうなるか | 成膜時のひずみ、緩和、冷却、基材の戻りと膜応力の変化。 |
| プロセス張力と巻取り張力は同じか | 駆動・張力制御区間、滑り、巻径、テーパ張力、採取時の状態。 |

**最低限の記録候補：** 幅・厚さ、各区間の張力、荷重計位置、ドラム半径、巻付け、温度、伸び・しわ・蛇行・滑り、巻取り後の変形。

### 3.6 5因子を独立とみなさない

| 組合せ | 学習する主な相互作用 |
|---|---|
| 出力 × 圧力 | 放電、輸送、反応、熱の同時変化。 |
| 出力 × O₂制御 | 金属供給と反応消費、ターゲット状態、膜組成。 |
| 出力 × 速度 | 膜厚補正、積算入熱とピーク温度、照射履歴。 |
| 冷却 × 速度 | ドラム上の冷却時間とフィルムの温度履歴。 |
| 冷却 × 張力 | 接触熱抵抗と熱・力学的な応答。 |
| 温度 × 張力 | 基材の弾性率・クリープ・寸法変化、膜形成時のひずみ。 |

O₂制御は重点5因子に数えていないが、**反応性スパッタの条件設計では省略できない背景条件**として扱う。

## 4. 教科書へ展開するときに扱う式と適用条件

以下は学習対象の基本式・近似式であり、実機の保証値を与える式ではない。記号、単位、導出、仮定、使えない例を必ずセットで説明する。

| 学習対象 | 式・関係 | 適用時に確認すること |
|---|---|---|
| 定常DC電力 | $P=\lvert V\rvert I$ | 電圧・電流の定義、電源の計測点、配線損失。 |
| パルス・RFの平均電力 | $\bar P=\langle V(t)I(t)\rangle$ | 平均電圧×平均電流と一般には一致しない。RFは位相・整合・損失を含める。 |
| 出力密度 | $P/A$ | Aを全面積とするか侵食面積とするか統一し、異なる定義を比較しない。 |
| 平均自由行程の基礎近似 | $\lambda=k_BT/(\sqrt{2}\pi d_{\mathrm{col}}^2p)$ | 熱平衡の単一硬球気体モデル。高速Si/Nb粒子には適切な衝突断面積・相対速度が必要。 |
| ガス収支の基礎 | $Q=S_{\mathrm{eff}}p$ | 定常・単純系の関係。反応性では壁・ターゲット・基材の消費やガス放出を収支へ加える。 |
| 滞在時間 | $t_{\mathrm{exp}}=L/v$ | ゾーン長Lと速度vの単位、加減速、空間分布。 |
| 移動基材の膜厚 | $d_f=(1/v)\int r(x)\,dx$ | 定常、一定速度、実効堆積速度r(x)。反応状態・再スパッタ・パス数を別途考慮。 |
| 水側の熱回収 | $\dot Q=\dot m c_p(T_{\mathrm{out}}-T_{\mathrm{in}})$ | 冷却回路全体の回収熱であり、フィルムだけの熱ではない。 |
| フィルムからドラムへの放熱 | $q''=h_c(T_f-T_d)$ | 有効熱伝達係数h_cは接触・表面・ガス等に依存し、装置の普遍定数ではない。 |
| 薄い移動基材の簡略熱収支 | $C_A\,dT_f/dt=q''_{\mathrm{in}}-h_c(T_f-T_d)$ | 面積熱容量C_A、厚さ方向温度差の無視、放射等の扱いを明記。 |
| 単位幅張力 | $N_w=F/b$ | 総張力F、幅b、どの制御区間かを明記。 |
| ドラムへの平均接触圧の近似 | $p_c\approx N_w/R$ | 薄く柔軟なウェブ、既に巻き付いている区間、一定張力等の近似。微視的接触面積を直接は与えない。 |
| 薄い単一基材の平均引張応力 | $\sigma\approx F/(b t_s)=N_w/t_s$ | 多層では荷重分担、粘弾性、温度、局所応力を別途評価する。 |
| 光学膜厚 | $n d_f$ | 波長・偏光・入射角、k、異方性、実膜厚との違い。 |
| 物性比較の補助指標 | $H/E$、$H^3/E^2$ | 密着・靭性・摩耗の直接測定ではなく、測定法と膜／基材影響に注意する。 |

参考：真空基礎はR1、膜成長のエネルギー整理はR2、熱収支・R2R熱接触はR4・R5、光学評価はR8、薄膜力学計測の注意はR9。

## 5. 学習時に固定しておく「誤解しやすい点」

| 誤った短絡 | 教材で維持する区別 |
|---|---|
| 高出力ほど飛来原子1個のエネルギーが高い | 出力、電圧、粒子数、粒子種、エネルギー分布、堆積原子あたり投入量は別の量。 |
| 低圧×高出力なら必ず緻密で摺動に強い | 有力仮説になり得ても、反応不足、損傷、応力、下地変形等で逆転し得る。 |
| O₂流量一定なら酸化状態一定 | 出力・被覆率・排気・壁面状態で供給と消費の収支が変わる。 |
| 同じPEM値・O₂分圧なら必ず同じ組成 | 発光の励起条件、基準化、表面除去速度、基材側供給等の違いを確認する。 |
| 冷却水温＝フィルム温度 | ドラム・界面・フィルムの熱抵抗と過渡的な温度差がある。 |
| 速度を上げれば必ず低温になる | 入熱源固定か、同一膜厚のため出力を増やしたかで比較が変わる。 |
| 同じ膜厚にすれば速度の純粋な効果が分かる | 補正に使った出力・パス・開口の変更が別の影響を持つ。 |
| 張力は冷却だけに効く | 基材のひずみ、搬送不良、成膜後の応力状態にも関わる。 |
| 圧縮応力は単純に引張クラックを増やす | 引張割れと圧縮座屈・剥離を区別し、積層・拘束・負荷を考える。 |
| 硬さやH/Eだけで耐摩耗性を判定できる | 破壊機構、密着、残留応力、下地支持、摩擦、相手材、移着を確認する。 |
| nが高い＝高密度＝高摺動耐性 | 組成、結合、欠陥、吸収、光学モデルも確認し、摺動は別に測定する。 |
| 厚膜の随伴試料なら本製品の膜質が分かる | 厚さ・基板・温度・成長段階が違うため、補助証拠として扱う。 |
| 目視のスジ＝膜が削れた溝 | 移着、微細割れ、剥離、表面処理変化、光学的な見え方も候補に残す。 |

この表は一般的な断定を避けるための確認項目である。個別の膜でどの機構が支配的かは、測定と比較実験によって決める。[R1〜R5、R8〜R10]

## 7. 学習と実務をつなぐ演習案

以下は演習のテーマであり、実機レシピの指定ではない。数値データがない場合は仮想データと明示して計算・設計演習にできる。実験は設備の許容範囲と承認手順に従う。

| 演習 | 目的 | 成果物 |
|---|---|---|
| 1. 装置を読み解く | 設定できるものと、結果として観測するものを区別する。 | 設備構成・制御モード・記録項目の一覧。 |
| 2. 成膜速度を校正する | QCM、実膜厚、出力、搬送速度の対応を把握する。 | 校正表、残差、再現性、適用できる範囲。 |
| 3. 反応状態を整理する | ガス流量だけで説明できない状態変化を理解する。 | 既存ログから作るV/I・発光・分圧・膜組成の比較表。 |
| 4. 出力×圧力を検討する | 交互作用と反応・膜厚・温度の交絡を認識する。 | 仮説表、試験順序、固定条件と観測項目、判定基準。 |
| 5. R2Rの熱を把握する | 水温・速度・張力と実フィルム温度をつなぐ。 | 測温計画、熱収支、簡略モデル、測定上の限界。 |
| 6. 摺動のスジを分類する | 溝・移着・割れ・剥離等を区別する。 | 観察記録、対照試料、候補原因と追加分析。 |
| 7. 最上層と積層を比較する | 光学・応力・下地支持・表面処理を統合する。 | 積層別の利点・副作用と確認評価の表。 |
| 8. 基準条件を移管する | 1回の成功を、再現する条件窓へ変える。 | 条件台帳、管理範囲、異常判定、再確認方法。 |

## 11. 最終的な習得の確認

次の問いに、条件・根拠・限界を添えて答えられれば、少なくとも「設定値の暗記」から「実務の条件設計」へ進めている。

1. 出力と圧力を変えたとき、膜厚・組成・密度・応力・温度の何が変わったかを区別できるか。
2. 同じO₂流量・同じPEM値でも、同じ膜とは限らない理由を説明できるか。
3. 水温・速度・張力から実フィルム温度を考える際、必要な測定と未知の量を挙げられるか。
4. 摺動の見え方と、実際の摩耗・破壊・移着を区別する確認方法を提案できるか。
5. 膜厚補正や随伴試料を使った比較で、まだ残る交絡と限界を説明できるか。
6. 最良条件1点ではなく、再現する条件窓・管理項目・停止基準を提案できるか。

**中心に置くのは、「何を動かせるか」だけでなく、「何が変わったかをどう確かめ、どこまで結論できるか」である。**
