# 個人哲学・行動原則台帳

## 0．この台帳の目的

哲学や経験から得た考えを、名言集ではなく、**実際の判断で使い、Decision Caseによって検証できる原則**として管理します。

この台帳は完成品ではありません。原則は実生活で試し、必要に応じて修正・統合・廃止します。

### 運用上の重要ルール

- AIが生成しただけの原則は `DRAFT` とする。
- `ADOPTED` への正式採用は本人が明示的に決める。
- 原典の意味、自分用の解釈、行動ルールを分ける。
- 一回の成功・失敗だけで、原則を自動昇格・廃止しない。
- 原則の変更時は、古い記述を消さず更新履歴を残す。
- 似た原則を増やしすぎず、中核原則は5〜10件程度を目安にする。
- 適用場面が違う原則は、表現が似ていても無理に統合しない。

### 矛盾整理の補助質問

1. 本当に両立不能か、それとも適用場面が違うだけか。
2. 争いは事実認識か、価値の順位か。

4. 短期と長期で優先順位が変わるか。
5. 他者の権利・安全・合意へどう影響するか。
6. どの情報が得られれば判断が逆転するか。
