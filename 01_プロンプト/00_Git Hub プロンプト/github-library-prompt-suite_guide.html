基本的な使い方

  1. 目的に合う番号のMarkdownファイルを開き、マスタープロンプト全体をAIへ渡します。
  2. 末尾の入力欄へ、対象フォルダ、既存ファイル、希望モード、変更条件を記入します。
  3. 生成された成果物を保存し、プロンプト内のセルフチェックとリポジトリの既存検証を実行します。
  4. 次の番号へ進みます。既存資料の更新では、必要な工程だけを選んで構いません。
原本を先に守ります。 Markdownは内容の正本、HTMLは閲覧版、画像はプレビュー、meta.jsonは構造、library.jsonは集約索引という役割分担です。
