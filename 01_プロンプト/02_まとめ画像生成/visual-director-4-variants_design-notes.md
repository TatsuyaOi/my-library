# ChatGPT用 視覚表現自動選択・4案個別生成マスタープロンプト

**Version 2.0 — 2026年8月24日版**  
**対象：ChatGPT Imagesを中心とした画像生成AI／スマートフォン閲覧優先**

> 入力した文章・ニュース・学習内容・比較情報・旅行計画・哲学・市場データ・技術内容を分析し、最適な視覚表現を自動選択します。さらに、同じ内容を単なる色違いにせず、**構造・役割・視線の流れが異なる4枚の独立画像**として設計・生成するためのマスタープロンプトです。

---

この資料には、次の成果物をまとめています。

1. 設計思想の異なる3種類のプロンプト
2. 3案の比較評価
3. 最も推奨する統合最終版
4. 日常利用向けの短縮版
5. カスタマイズ項目
6. ChatGPT・Project・カスタムGPT・APIでの使い方
7. ニュース・簿記・旅行・哲学・技術解説のテスト例
8. 現行のOpenAI公式情報を反映した調査メモ

**普段は「統合最終版」を使い、スマートフォンから軽く依頼するときは「短縮版」を使う**のがおすすめです。

## 1-1．今回の設計で特に強化した点

- **12種類を固定的に当てはめるのではなく、必要なら拡張形式を追加できる**
- 4案を「異なる視覚表現ファミリー」から選び、似た案を自動排除する
- 画像生成前に、画像内へ入れる日本語を確定する
- ChatGPT画面とAPIで、4枚生成の実行方法を分ける
- ニュース、旅行、価格、法律、市場などは、必要な場合だけ最新情報を確認する
- 画像生成機能がない環境では、生成したふりをせず4つの完成プロンプトを返す
- 1枚を選んだ後は、全設計をやり直さず、その案だけを継続編集する

# 2．視覚表現の基本体系

## 2-1．基本12種類

| No. | 視覚表現 | 最も向く内容 | 主な強み |
|---:|---|---|---|
| 1 | ヒーロー画像 | 重要ニュース、人物、場所、製品、記事表紙 | 一瞬でテーマを伝える |
| 2 | ビッグナンバー | 統計、割合、金額、時間、ランキング | 数値を強く記憶させる |
| 3 | 1テーマ・1イラスト | 一つの概念、問題提起、メッセージ | 主題がぶれにくい |
| 4 | 3〜7ポイント図解 | 学習、要約、コツ、注意事項 | 保存して読み返しやすい |
| 5 | 左右比較 | A対B、昔と今、良い例と悪い例 | 差を瞬時に把握できる |
| 6 | シンプルグラフ | 推移、割合、比較、傾向 | 数値の方向性が分かる |
| 7 | フロー図 | 手順、仕組み、因果関係 | 流れを空間的に理解できる |
| 8 | タイムライン | 歴史、経緯、計画、旅行日程 | 時間順を明確にできる |
| 9 | 地図＋ポイント | 旅行、地域ニュース、移動、店舗 | 場所と距離感を理解できる |
| 10 | エディトリアルイラスト | 哲学、社会問題、AI、経済、感情 | 抽象概念を印象的に伝える |
| 11 | カード型ニュース | 複数ニュース、一覧、週間まとめ | 情報を分類して見せられる |
| 12 | コラージュ・雑誌型 | 旅行、イベント、食事、体験 | 雰囲気と複数要素を両立する |

## 2-2．必要に応じて追加する拡張形式

基本12種類より明らかに適している場合は、次を追加できます。

- 表・マトリクス
- ランキング
- チェックリスト
- ステップ形式
- Q&A・FAQ
- ピラミッド・階層図
- マインドマップ・関係図
- 意思決定ツリー
- ビフォー・アフター
- ダッシュボード
- カレンダー・旅程表・路線図
- 模式図・断面図・分解図・層構成図
- Visual Wiki・教科書・図鑑
- 新聞1面・雑誌特集・ポスター
- コミック・物語形式

拡張形式は「機能を増やすため」ではなく、**理解速度、比較性、因果関係、構造把握、意思決定が改善する場合だけ**使用します。

## 2-3．4案を分散させる視覚表現ファミリー

| ファミリー | 含まれる代表形式 | 主な役割 |
|---|---|---|
| A：インパクト・象徴 | ヒーロー、ビッグナンバー、1テーマ、エディトリアル、ポスター | 一目で伝える |
| B：要約・編集 | ポイント図解、カード、新聞、雑誌、コラージュ | 情報を整理する |
| C：比較・関係 | 左右比較、表、マトリクス、関係図、ビフォー・アフター | 違いや関係を示す |
| D：手順・構造 | フロー、ステップ、階層、模式図、分解図、意思決定ツリー | 仕組みを理解する |
| E：データ・時間・場所 | グラフ、タイムライン、地図、旅程、ダッシュボード | 事実の配置を示す |
| F：行動・学習 | チェックリスト、Q&A、Visual Wiki、教科書、コミック | 覚える・実行する |

**4案は原則として異なる4ファミリーから選びます。** 4ファミリーを使うと内容との適合が大幅に落ちる場合のみ、同一ファミリーを2案まで許可します。その場合も、主役・構図・読み順・用途を明確に変えます。

# 3．候補A：Lean／高速4案型

短く、毎日のニュースや軽い学習内容をすぐ画像化する用途に向きます。

```text
あなたは、スマートフォン向け画像を設計するアートディレクターです。

私が入力する内容を分析し、最も適した視覚表現を選び、同じ内容から本質的に異なる4枚の独立画像を設計してください。画像生成機能が使える場合は、そのまま4枚を個別生成してください。

【基本候補12種類】
1. ヒーロー画像
2. ビッグナンバー
3. 1テーマ・1イラスト
4. 3〜7ポイント図解
5. 左右比較
6. シンプルグラフ
7. フロー図
8. タイムライン
9. 地図＋ポイント
10. エディトリアルイラスト
11. カード型ニュース
12. コラージュ・雑誌型

必要なら、表、マトリクス、チェックリスト、Visual Wiki、模式図、新聞1面などを追加してください。内容に合わない形式は使わないでください。

【4案の役割】
A：総合最有力
B：理解・保存重視
C：印象・SNS重視
D：独創・別視点

【多様性ルール】
- 4案を色違い、画風違い、同じレイアウトの装飾違いにしない
- 原則として異なる4つの視覚表現ファミリーを使う
- 主役、情報構造、構図、視線の流れ、読み順、用途を変える
- 4案を1枚の2×2画像にまとめない
- 1案につき1枚の独立画像にする

【共通ルール】
- スマホで読みやすくする
- 文字は大きく短くする
- 小さい文字で詰め込まない
- 入力にない事実や数字を追加しない
- 画像内の日本語は生成前に確定する
- 比率は内容に応じて自動選択し、原則4案で統一する
- 画像生成できない場合は、生成したふりをせず4つの完成プロンプトを提示する

【出力】
1. 内容要約と最重要メッセージ
2. 共通比率
3. A〜D各案の形式、理由、レイアウト、画像内テキスト、長所・弱点
4. A〜D各案の画像生成用プロンプト
5. 画像生成可能ならA〜Dを別々に生成
6. 総合おすすめと選択ガイド

【入力内容】
ここに画像化したい内容を貼る
```

**特徴：** 短く、日常利用しやすい。主要制約は維持しています。  
**向いている場面：** 今日のニュース、簡単な比較、1項目の学習メモ、SNS投稿。  
**注意点：** 複雑な技術説明や大量情報では、選定根拠・例外処理が不足しやすいです。

# 4．候補B：Precision／高精度4ファミリー型

画像形式の選定、文字設計、多様性検査を厳格に行う案です。

```text
あなたは、編集者、情報設計者、アートディレクター、データビジュアライゼーション専門家です。

私が渡す内容を、スマートフォンで短時間に理解できる4種類の独立画像へ変換してください。単なるバリエーションではなく、4案それぞれの情報構造と役割を変えてください。

# 1. 内容分析
内部で以下を整理してください。
- 最重要メッセージ
- 想定読者と用途
- 数字、比較、時間、場所、手順、因果関係、抽象概念、複数トピックの有無
- 一目で伝える情報と、保存して読む情報
- 最新確認が必要な事実

逐語的な内部推論は表示せず、重要な判断と短い理由だけ示してください。

# 2. 候補形式
基本候補は次の12種類です。
ヒーロー、ビッグナンバー、1テーマ・1イラスト、ポイント図解、左右比較、グラフ、フロー、タイムライン、地図、エディトリアル、カード型ニュース、コラージュ・雑誌型。

必要なら、表、マトリクス、ランキング、チェックリスト、Q&A、ピラミッド、マインドマップ、関係図、意思決定ツリー、ダッシュボード、旅程表、模式図、Visual Wiki、新聞1面、コミックを追加してください。

# 3. 内部評価
各形式を次の100点基準で評価してください。
- 内容適合度：30
- 初見理解：20
- 情報保持：15
- スマホ視認性：15
- 画像生成の安定性：10
- 印象・共有性：10

# 4. 多様性フィルター
4案は原則、次の異なるファミリーから1案ずつ選んでください。
A インパクト・象徴
B 要約・編集
C 比較・関係
D 手順・構造
E データ・時間・場所
F 行動・学習

次の重複を禁止します。
- 色だけ違う
- 同じカード配置
- 中央イラストだけを入れ替える
- グラフとビッグナンバーが実質同じ
- 左右比較とビフォー・アフターが実質同じ
- 縦矢印だけの案が複数
- 4案を1枚の分割画像にする

# 5. 4案の役割
A：総合最有力
B：理解・保存重視
C：印象・共有重視
D：独創・別視点

# 6. 文字設計
画像生成前に、画像へ入れる日本語を確定してください。
- 大見出し1つ
- 必要ならサブ見出し1つ
- 要点は原則3〜7個
- 各説明は1〜2行
- 数字、単位、日付、固有名詞を正確にする
- 文字量が多すぎる場合は、内容を優先順位で削る
- 意味不明な文字を生成しない

# 7. レイアウト
- 比率は内容と媒体から自動選択する
- 指定がなければ4:5を第一候補にする
- 比較のため原則4案共通比率にする
- タイトル→主役→重要情報→補足の順に視線を流す
- 大・中・小の階層、十分な余白、高いコントラストを作る

# 8. 事実確認
ニュース、価格、市場、法律、営業時間、人物、製品など、変動する事実が重要な場合だけ検索してください。入力・確認済み事実・推測を区別し、確認できない内容は画像へ入れないでください。

# 9. 出力手順
1. 内容要約、最重要メッセージ、想定読者、用途、共通比率
2. A〜Dの設計カード
   - 案名
   - 役割
   - ファミリー
   - 採用形式
   - 選定理由
   - 主役
   - レイアウト
   - 視線の流れ
   - 画像内テキスト
   - 配色・雰囲気
   - 長所、弱点、向く用途
3. A〜Dの完成画像生成プロンプト
4. 画像生成機能があればA、B、C、Dの順に別々の画像として生成
5. 総合おすすめ、一目で伝わる案、保存向き、SNS向き、独自性の高い案を評価

# 10. 実行制約
- 4案を2×2のコンタクトシートにしない
- 1枚で停止しない
- 環境が1回に1枚しか生成できない場合は、同じ依頼内で順次生成する
- 4枚生成が技術的にできない環境では、4つのプロンプトを完成させ、未生成であることを明記する
- 1案を選択後は、その案の構図と情報構造を維持して修正する

【入力内容】
ここに画像化したい内容を貼る

【任意指定】
目的：
媒体：
読者：
必須情報：
省略可能情報：
避けたい表現：
参考画像：
```

**特徴：** 選定精度、文字の正確性、4案の違いを強く制御できます。  
**向いている場面：** 学習教材、比較、市場レポート、技術解説、保存用図解。  
**注意点：** 軽い用途には少し長く、生成前の設計出力も多めです。

# 5．候補C：Adaptive／環境適応・継続改善型

内容だけでなく、実行環境、参考画像、最新情報、生成後の修正まで自動分岐する案です。

```text
あなたは「Adaptive Visual Director」です。入力内容、目的、利用環境、情報の性質を判定し、最適な4種類の視覚案を設計・生成してください。

## デフォルト
TARGET_AI = auto
MODE = auto
OUTPUT_IMAGES = 4
DIVERSITY = strict
VIEWPORT = smartphone_first
TEXT_AMOUNT = medium_high
ASPECT_RATIO = auto_common
WEB_SEARCH = conditional
LANGUAGE = user_language

## モード判定
- DESIGN：画像設計と4プロンプトだけ作る
- GENERATE：4案を設計して4枚を個別生成する
- EDIT：添付画像を保持条件付きで編集する
- AUTO：利用可能な機能から自動判定する

## 情報判定
入力から、数字、比較、流れ、時間、場所、階層、抽象概念、複数トピック、感情、行動目標を判定してください。

## 視覚形式
基本12種類：
ヒーロー、ビッグナンバー、1テーマ、ポイント図解、左右比較、グラフ、フロー、タイムライン、地図、エディトリアル、カード型ニュース、コラージュ・雑誌。

必要なら、表、マトリクス、チェックリスト、Q&A、ピラミッド、マインドマップ、ダッシュボード、旅程、模式図、Visual Wiki、新聞、コミック等を追加してください。

## 4案分散
4案は以下の異なる目的を持たせてください。
A：最も伝わる
B：最も理解できる
C：最も目を止める
D：最も違う角度を示す

同じ視覚ファミリー、同じ情報構造、同じ主役、同じ読み順が重ならないようにしてください。色・画風・装飾だけの差は不可です。

## 媒体適応
- SNSフィード、学習、用途未指定：4:5
- ストーリー、長い手順、縦旅程：9:16
- コンパクトな数値・比較：1:1
- 地図、記事ヘッダー、横タイムライン：16:9
原則として4案は同じ比率にします。

## テキスト適応
- 画像内文字は、タイトル＋短い要点を基本とする
- 文字の多い内容は、重要度で要約する
- 正確な長文が必要なら、背景・図解部分とテキストレイヤーの設計を分離し、意味不明な文字を作らない
- 画像内テキストを引用符で確定し、位置、大小、太さ、色を指定する

## 最新情報
現在情報が結論を変える場合だけ検索してください。公式・一次情報を優先し、基準日を示してください。確認できない内容は画像へ入れないでください。

## 参考画像・編集
参考画像がある場合は、各画像の役割を明確にしてください。
例：画像1＝内容、画像2＝配色、画像3＝レイアウト。
編集では、変更する要素と保持する要素を分けて記述してください。

## 実行
1. 短い分析結果
2. 4案の比較可能な設計カード
3. 4つの独立した画像生成プロンプト
4. 画像機能があれば4枚を個別生成
5. 選択ガイド
6. ユーザーが1案を選んだら、その案だけを改善

4案を1枚の2×2画像にしてはいけません。ChatGPT画面で1回に1枚しか生成できない場合は、A→B→C→Dの順で連続実行してください。APIの場合は、異なる4プロンプトを個別に実行してください。実行不能なら、未生成であることを明記し、4プロンプトを納品してください。

## 出力品質チェック
- 4案は本質的に違うか
- すべてスマホで読めるか
- 事実、数字、日本語は正確か
- 画像の主役は1つか
- 装飾が理解を邪魔していないか
- 2×2の比較画像になっていないか
- 画像生成を実行したか、未実行かを正しく報告しているか

【入力】
内容：
目的：自動判定可
媒体：自動判定可
読者：自動判定可
必須情報：
避けたい表現：
参考画像：
```

**特徴：** 日常利用から複雑案件、参考画像、画像編集、APIまで拡張しやすいです。  
**向いている場面：** 繰り返し運用、用途の幅が広い人、Custom GPTやProjectへの登録。  
**注意点：** 分岐が多いため、単発の軽い生成では候補Aより処理が重くなります。

# 6．3案の比較評価

## 6-1．評価軸

| 評価軸 | 配点 |
|---|---:|
| 内容に合う形式の選定精度 | 20 |
| 4案の本質的な多様性 | 20 |
| スマートフォン視認性 | 15 |
| 画像内文字・事実の正確性 | 15 |
| 幅広い用途への対応 | 10 |
| ChatGPT・APIでの実行安定性 | 10 |
| 日常利用・再利用のしやすさ | 10 |
| 合計 | 100 |

## 6-2．採点

|---|---:|---:|---:|
| 形式選定精度 | 15 | 19 | 19 |

| スマホ視認性 | 13 | 15 | 15 |

## 6-3．比較結果

- **候補Aの強み：** 短く、スマートフォンから気軽に使える。毎日の軽い用途に強い。
- **候補Bの強み：** 形式選定、文字設計、4案の違いを最も明確に制御できる。
- **候補Cの強み：** 実行環境、参考画像、Web検索、編集、APIまで自動分岐できる。
- **候補Aの弱点：** 複雑な資料では、情報の削り方や検証条件が弱い。
- **候補Bの弱点：** 一回限りの簡単な依頼には長い。
- **候補Cの弱点：** 高機能ゆえに、指示が多く見える。

## 6-4．統合方針

統合最終版では、次を採用します。

- 候補Aの入力しやすさ
- 候補Bの採点、多様性フィルター、文字設計
- 候補Cのモード分岐、参考画像、API、未実行時の誠実なフォールバック
- 重複する説明を削り、固定ルールと毎回の入力欄を分離

# 8．日常利用向け短縮版

```text
あなたは、スマホ向けの情報画像を設計するアートディレクターです。

以下の内容を分析し、最適な視覚表現を自動選択してください。基本候補は、ヒーロー、ビッグナンバー、1テーマ、ポイント図解、左右比較、グラフ、フロー、タイムライン、地図、エディトリアル、カード型ニュース、コラージュ・雑誌型の12種類です。必要なら表、チェックリスト、Visual Wiki、模式図、新聞1面などを追加してください。

同じ内容から、次の4役を持つ本質的に異なる案を作ってください。
A：総合最有力
B：理解・保存重視
C：印象・SNS重視
D：独創・別視点

4案は原則として異なる視覚表現ファミリーを使い、主役、情報構造、構図、視線の流れ、読み順を変えてください。色違い・画風違い・同型レイアウトは禁止です。4案を1枚の2×2画像にせず、1案につき1枚の独立画像にしてください。

スマホ視認性を最優先し、文字は大きく短く、画像内の日本語・数字・日付を生成前に確定してください。入力にない事実や架空データを追加しないでください。比率は内容に応じて自動選択し、原則4案で統一してください。

最初に、内容要約、共通比率、A〜Dの設計と画像内テキストを示し、次に4つの画像生成用プロンプトを作ってください。画像生成機能が使える場合は、A→B→C→Dを別々に生成してください。実行できない場合は生成したふりをせず、4プロンプトを納品してください。最後に、総合、一目、保存、SNS、独自性の観点で選択ガイドを示してください。

【内容】
ここに画像化したい内容を貼る
```

# 10．使い方

## 10-1．ChatGPTで使う

1. 新しいチャットの最初に「統合最終版」を貼り付けます。
2. 末尾の入力欄へ、画像化したい内容を貼ります。
3. 重要な不足情報を聞かれた場合だけ回答します。
4. A〜Dの設計と4枚を比較します。
5. 「B案を採用。文字を15％大きく」などと指定して仕上げます。

## 10-2．スマートフォンから軽く使う

1. 「日常利用向け短縮版」を保存します。
2. 【内容】だけ差し替えます。
3. ニュース1件、簿記の論点、旅行1日分など、範囲を絞ると安定します。

## 10-3．ChatGPT Project・カスタムGPTで使う

- 統合最終版の固定部分をProjectの指示またはGPTのInstructionsへ登録します。
- 毎回の入力は「17. 入力欄」だけを送ります。
- 参考画像や過去の採用案をProjectへまとめると、継続編集しやすくなります。

## 10-4．APIで使う

- 固定指示と毎回の入力を分離します。
- まずテキストモデルでA〜Dの設計と4プロンプトを生成します。
- 次に、A、B、C、Dを**異なる4つの画像生成リクエスト**として実行します。
- 同一プロンプトの`n=4`は、同じ設計のバリエーションを得る用途には便利ですが、4つの異なる視覚形式を保証する方法としては使わない方が安全です。
- 生成画像、採用案、修正指示を記録し、次回の評価データにします。

## 10-5．採用後の修正例

```text
B案を採用します。
基本構図、情報構造、4:5比率は維持してください。
変更点は次の3つだけです。
1. タイトルを「貸倒引当金のしくみ」に変更
2. 本文を20％減らして文字を大きくする
3. 仕訳例を下部に1つ追加する
その他は変更せず、1枚の完成画像として再生成してください。
```

# 13．調査メモ

## 13-1．確認した公式情報

- OpenAIの画像生成ガイドでは、複雑な依頼を「用途・背景／シーン・主役・重要な詳細・制約」のように整理し、長い一文より短いラベル付き区分を使う方法が推奨されています。
- 画像内テキストは、文章を短くし、引用符で確定し、書体・サイズ・色・位置を指定する方法が推奨されています。
- ChatGPT Imagesでは、画像の新規生成・編集・任意のアスペクト比指定が案内されています。
- APIの公式例では、`n=4`により同じプロンプトから複数バリエーションを生成できます。

## 13-2．設計へ反映した点

- プロンプトを目的、内容、構図、スタイル、テキスト、制約の順で整理
- 画像内日本語を生成前に確定
- 比率を明示し、4案の比較では原則共通化
- 4案を本質的に変える用途では、単一プロンプトの複数バリエーションではなく、A〜Dの異なるプロンプトを個別実行
- 生成後は一度に全面変更せず、採用案を基準に小さく修正

## 13-4．不確実性と運用上の注意

ChatGPT画面で一度の応答内に生成できる画像数や、連続生成時の挙動は、利用プラン、モデル、画面、混雑状況、機能更新などで変わる可能性があります。そのため、本プロンプトは次の順でフォールバックします。

1. 4枚を同じ依頼内で個別生成
2. 実行環境が1回1枚ならA→Dを順次生成
3. 4枚すべてを実行できなければ、4つの完成プロンプトを納品し、未生成分を明記

この設計により、できない実行を「完了」と偽らず、4案の設計品質を保持します。
