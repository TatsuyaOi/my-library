# 4役分離・連続2回95点 Quality Gate 短縮版

**Version 1.1 — 2026年8月27日生成**

以下の成果物を、95点相当になるまで厳格に改善してください。単一AIの自己採点を甘くしないため、処理を4役へ分離します。

1. **作成者**：生成・修正だけを行い、自分で採点しない
2. **批判者**：成果物を修正せず、根拠付きのワースト5を抽出する
3. **独立採点者**：作成者の弁明・過去得点・批判者のSeverityを最初は見ず、凍結Rubricでゼロから採点する
4. **最終検査者**：得点上限制、回帰、採点操作、連続合格を検査する

可能なら4役を別エージェント・別セッションで実行してください。同一会話しか使えない場合は入力・権限・出力を分けた模擬ブラインド方式とし、真の独立評価と偽らないでください。

作業前に、目的、必須条件、禁止事項、出力形式、情報源、検証方法、100点Rubric、Hard Gateを確定して凍結してください。合格しやすくするため途中で配点や重大度を変更してはいけません。

標準Rubricは、要求充足25、正確性20、網羅性15、論理性10、明確さ10、実用性10、効率性5、検証・安全性5です。タスクに合わせてROUND 1前だけ調整できます。

各ROUNDで批判者は、対象箇所、Severity、違反要件、証拠、影響、修正条件、確認方法を含むワースト5を示してください。同じ原因の言い換えで水増しせず、問題が少ない場合は相対的弱点として正直に示してください。

得点上限制：

- Criticalが1件以上残る場合は最大79点
- Highが1件以上残る場合は最大94点
- 必須条件未達、重大誤り、重要な未確認、形式未達、必須検証失敗、重大回帰がある場合は95点以上禁止

採点操作を禁止します。配点変更、問題の無視、未修正項目への加点、長さ・努力・見栄えだけの加点、94点台の丸め、2回の平均による合格、自作物への優遇を行ってはいけません。前回得点へ加点せず、毎回現在の成果物をゼロから採点してください。

改善は、作成 → 批判 → 独立採点 → 最終検査 → 差戻し、の順で自動反復してください。ユーザーへ「続けますか」と確認して停止しないでください。

合格候補が出たら成果物とRubricを凍結し、同一成果物を2回連続で採点します。

- PASS 1：必須条件・正確性・完全性・形式中心
- PASS 2：失敗パターン・反例・境界条件・実運用中心

2回とも個別に95点以上で、Critical 0、High 0、必須未達0、重大誤り0、必須検証失敗0、重大回帰0、採点操作なしの場合だけ合格です。PASS間で1文字でも変更した場合、Rubric変更、新要件追加、重要情報源更新があった場合は連続回数を0へ戻してください。

到達に必要な資料・検索・ツールがない場合は95点を偽装せず、`STATUS = UNRESOLVED`、現在点、阻害要因、必要情報、再開地点を示してください。

最終出力では、PASS 1得点、PASS 2得点、候補Versionまたはfingerprint、Critical / High / 必須未達数、回帰、独立性（実分離／模擬分離）、最終的に残る相対的弱点5点、完全な最終成果物を示してください。内部の逐語的な思考過程は表示しないでください。
