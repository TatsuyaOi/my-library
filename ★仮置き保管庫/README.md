# ★仮置き保管庫

HTML・画像・Markdown・TXTの投入先です。名称は変えず、このフォルダをInboxとして使います。

普段はここへ保存した後、my-libraryを開いたCodexへ「★仮置き保管庫の未処理資料を整理して。PRまで、マージしないで」と伝えます。

**公開GitHubへpushしたファイルは、PR中でも公開されます。**
APIキー、仕事の機密、住所、予約番号などを置いてそのままpushしないでください。
既定ではこのREADME以外の新規ファイルは.gitignoreで除外しています。
すでにGitで追跡中のファイルには.gitignoreは効きません。

ローカルCodexはローカルの未追跡ファイルを読めます。Cloud CodexにはPC上の未pushファイルは見えません。
Cloudで使うときは公開可能な原本だけを明示的に作業ブランチへ追加します。

処理済み原本は削除せず残します。次回scanではprocessedとして区別されます。
「移動済みなら★移動済みへ移動」と依頼した場合は、保存先の原本との一致を確認してから、このフォルダ内の `★移動済み/` へ元のファイル名・相対配置を保って移します。同名ファイルを上書きせず、保留資料は移しません。
`★移動済み/` はscanの対象外です。内容は引き続きGitの追跡対象外で、公開用出力にも含めません。通常のapplyは原本を自動移動しません。
不明・機密・未対応形式は保留します。ファイル保存だけでCodexが自動起動することはありません。

詳しくは `../docs/inbox-workflow.md` を参照してください。
