4｜仮運用の標準手順

普段の起動XperiaをCX-30へUSB接続 → Android Auto → YTM再生 → Lyrics CompanionをMedia sourceに選択 → Google Maps → Dashboard
歌詞だけ切るスマホでLyrics Mode OFF。Lyrics Companionは通常Mediaカードとして残る。
完全に標準YTMへ戻すAndroid Autoのアプリ一覧からYouTube Musicを選択。
DHUPCテスト時だけヘッドユニットサーバーON。終了後は必ずOFF。
実車ヘッドユニットサーバーOFF。Android Studio・ADB・DHUは不要。
更新同じ.jksを使用しversionCodeを上げて上書き更新。Release版導入後はアンインストールしない。

5｜今後の運用方針

1.0.0日常運用で重大不具合なしを確認後に昇格。
1.1 Library管理FOUND / NOT_FOUND / ERROR / MANUAL_LRC一覧・検索・再検索。
1.1 Export / Importlyrics_libraryをZIP化し新端末へ復元。
1.1 手動LRCLRCLIBにない曲をMANUAL_LRCとして登録。
1.1 オフライン優先ローカルLibraryのみ使用。外部通信なし。
自宅メンテナンスWi-Fi時にNOT_FOUND曲をまとめて再検索。

取得優先順位

手動LRC → ローカル保存済みLRC → LRCLIBオンライン → 曲名＋Artist Fallback

6｜本運用で守ること

実車時DHU用ヘッドユニットサーバーはOFF。
署名鍵lyrics-companion-release.jksを別媒体にもバックアップ。
通知アクセスYTM MediaSession用途に限定。他通知本文は保存・外部送信しない。
歌詞個人利用前提。歌詞DBや歌詞入りAPKを再配布しない。
更新後Android/Android Auto大型更新後はDHU→実車の順で再確認。
誤一致ヒット率と誤歌詞リスクのバランスを保守的に維持。
