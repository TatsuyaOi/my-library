01 / PRODUCT

ToDoが中心。RPGは表示と達成感に。

初期版でできること

今日の予定とMainを決め、Taskを完了。Projectの進捗を確認し、必要なら完成・再開。XPとレベルは設定で表示を選びます。全データを端末へ保存し、手動で退避・復元します。

後で追加すること

集中タイマー、軽いチェック項目、日付別の完了履歴。職業・称号・宝箱・装備・ペット・通貨・戦闘は対象外。初期版に空の集中・履歴タブを置きません。

資料の読み方：同梱MDの確定機能仕様と、本HTMLの確定UI要件が優先。未指定の寸法や時間は「実装基準案」です。操作見本はHTMLの試作品です。本番Androidアプリ・APKの完成を示すものではありません。

03 / INTERACTIVE REFERENCE

画面を動かして確かめる

右側の画面は実際に操作できます。名前を押すと詳細、丸ボタンで完了。下の3タブで切り替えます。

  1. 完了とUndo：Mainを完了し、「元に戻す」で状態と今回のXPだけを戻す。
  2. Mainの置換：別Taskの詳細からMainに指定。以前のMainは通常一覧へ。
  3. Project完成：詳細で残件を確認し完成。再開後の再完成ではXPを重複付与しない。
  4. 設定：XP表示、文字、密度、完了ボタンの左右を切り替える。
  5. バックアップ：設定から書き出し、読み込み・現状退避・確認後に全体復元。

サンプルは説明用。本番初回はLv1・0 XP・作業データなし。音・振動は設定値のみ。分類の並び替え、Project検索、Project説明の独立入力は見本では省略。本番の実装範囲は仕様本文・設計案を参照。

外部通信なし。保存できるブラウザでは変更を保持します。HTMLのプレビューで操作できない場合は、ダウンロードしてブラウザで開いてください。

06 / MOTION & FEEDBACK

操作と動き

短い時間・色の変化は実装基準案。確定している機能ルールを変えず、操作結果を分かりやすくするための演出です。

きっかけ表示の変化と順番動きの案
Task完了保存成功 → DONE表示 → 新規付与があればXP反映 → Undo通知チェックと淡い緑を150〜220msで表示。XPは400ms以内で控えめに出す
厳密Undo完了前の状態とその操作のXP差分を戻す即反映。逆向きの派手な演出なし。10秒・直近1件が基準案
後日再開TODOへ。過去XPは維持状態ラベルを更新。「獲得済みXPは維持」と短く案内
Main置換前Mainは通常一覧へ、新Mainは金色カードへ150〜200msのフェード案。自動スクロールや大移動を避ける
タブ切替対応する一覧を表示し選択状態を更新即時または120ms程度。過剰な横スライドなし
詳細・入力一覧上から詳細、戻ると元の一覧位置180〜220ms程度のシート表示案。HTMLでは中央ダイアログで代用
Project完成残件確認 → 保存 → 完成ラベルと初回XP300〜500ms程度の控えめな表示。宝箱・獲得品なし
表示設定変更文字・密度・左右配置が共通で反映選択後すぐプレビュー。レイアウトの跳ねを最小化
復元内容確認 → 現状退避 → 確認 → 処理 → 結果処理中は実行操作を重複させない。失敗時は理由と復旧結果
日跨ぎ・復帰端末日付で今日を更新、Mainを更新Taskを自動繰越しない。不要な達成演出なし

動作軽減ONまたは端末で動き抑制時は、移動・拡大・XP浮上を止めて即時の状態変化だけにする。音・振動は保存成功後に1回だけ。連打で何度も鳴らさない。HTMLの音・振動設定は値の確認のみで、実際の端末反応は起こしません。

戻る・閉じる・入力の扱い（設計案）

詳細から戻ると元のタブ・検索条件・スクロール位置を維持。編集中に未保存変更があれば破棄確認。Androidの戻ると画面内の戻るを同じ意味にする。確認ダイアログの外側タップはキャンセル相当、実行中は二重操作を防止。これらの本番挙動はHTMLの簡易ダイアログより優先します。
