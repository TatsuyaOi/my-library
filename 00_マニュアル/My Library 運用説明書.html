1

この仕組みの目的

My Libraryは、ChatGPT・Codexなどで作成したHTML資料をGitHubで一元管理し、GitHub PagesからPC・スマートフォンで読むための個人HTMLライブラリです。

ChatGPT / Codex ↓ HTML作成 ↓ PCの該当フォルダへ保存 ↓ GitHub Desktop ↓ Commit → Push ↓ GitHub Actionsが自動整理 ↓ GitHub Pages ↓ スマホのMy Library
最重要：普段は「HTMLを保存 → Commit → Push」まで覚えれば十分です。

GitHub Actionsが自動で行うこと

  • 各カテゴリ内のHTMLを探索
  • タイトル・説明・分類・タグを取得
  • 各カテゴリの library.json を生成
  • 全カテゴリ用 library-all.json を生成
  • 共通テンプレートを各カテゴリの index.html へ反映
  • GitHub Pagesの表示を更新

普段のHTML追加方法

例として、簿記の「貸倒引当金.html」を追加する場合です。

  1. ChatGPTなどで 貸倒引当金.html を作成する。
  2. my-library/12_簿記/ に保存する。
  3. GitHub Desktopを開く。
  4. 変更内容を確認する。
  5. Summaryへ 貸倒引当金教材を追加 などと入力する。
  6. Commit to main を押す。
  7. Push origin を押す。
  8. GitHub Actionsが自動実行される。
  9. 少し待ってMy Libraryを再読み込みする。
HTML追加 → Commit → Push
4

My Library用メタ情報

普通のHTMLでも自動登録されますが、次の情報を <head> に入れると一覧がより見やすくなります。

<meta name="library-title" content="貸倒引当金">
<meta name="library-group" content="決算">
<meta name="library-tags" content="簿記3級,仕訳,決算">
<meta name="library-description"
      content="貸倒引当金の意味・計算・仕訳を整理">
<meta name="library-pinned" content="false">
項目意味
library-title一覧に表示する資料名
library-group基礎・仕訳・決算などの小分類
library-tags検索に利用するキーワード
library-description一覧に表示する短い説明
library-pinnedtrue なら「★ よく見る」
library-order表示優先順位の補助設定
library-hiddentrue なら一覧から非表示

メタ情報がない場合のタイトル判定

library-title ↓ <title> ↓ 最初の <h1> ↓ HTMLファイル名
5

GitHub Desktopの4つの基本操作

操作意味
CommitPC上の変更を履歴として記録
PushPC → GitHubへ変更を送る
FetchGitHub側に新しい変更があるか確認
PullGitHub → PCへ最新変更を取り込む
GitHub Actions自身がJSONなどを自動Commitするため、Push後にPC側よりGitHub側が新しくなる場合があります。そのときは Fetch origin → Pull origin を実行します。

推奨する開始手順

GitHub Desktopを開く ↓ Fetch origin ↓ Pull origin があればPull ↓ HTMLの追加・編集を開始
6

HTMLの修正・削除・名前変更

修正

対象HTMLを編集して保存し、GitHub DesktopでCommit → Pushします。

削除

Windowsで対象HTMLを削除し、Commit → Pushします。GitHub Actionsが再生成され、My Libraryの一覧からも自動で消えます。

名前変更

Windows上でファイル名を変更し、Commit → Pushします。自動一覧も新しい名前・情報へ更新されます。

Commitメッセージは「減価償却教材を更新」「旧教材を削除」のように、何をしたか分かる文章がおすすめです。

カテゴリを管理する

カテゴリの設定は library.config.json で管理します。

"51_読書": {
  "title": "読書",
  "icon": "📚",
  "description": "読書ノート・書籍要約",
  "accent": "#7a5b3a"
}

カテゴリページのデザイン変更

各カテゴリの index.html を直接編集せず、assets/category-index.html を変更します。Push後、GitHub Actionsが全カテゴリへ反映します。

原則触らない：各カテゴリの library.json、library-all.json、各カテゴリの自動生成 index.html。
8

トラブル時の確認順序

HTMLを追加したのに表示されない

  1. HTMLが正しいカテゴリフォルダにあるか。
  2. Commitしたか。
  3. Push originしたか。
  4. GitHubのCode画面にHTMLが存在するか。
  5. Actions → Rebuild My Library indexes が緑色か。
  6. pages build and deployment が成功しているか。
  7. 数十秒〜数分待ってブラウザを再読み込みする。

Actionsが赤色になった場合

GitHub → Actions → Rebuild My Library indexes → 失敗した実行を開き、赤くなった工程を確認します。

主な原因はJSONの記述ミス、workflowやPythonスクリプトの変更ミス、書き込み権限などです。

9

公開リポジトリでの注意

My LibraryがPublicリポジトリの場合、保存内容は第三者から閲覧される可能性があります。

保存しないもの：
パスワード / APIキー / 個人情報 / 顧客情報 / 社外秘資料 / 会社の機密情報 / 未公開研究情報 / 社内限定データ

公開されても問題ない学習資料・一般情報だけを保存します。
