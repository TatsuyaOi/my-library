00最初に掴む全体像

所要 8分

この章の着眼点 反射を下げるために、波の何を整える？

反射防止膜（AR膜）の本質は、界面で生まれる複数の反射波を、振幅が等しく・位相が逆になるように重ねることです。光を吸収して消すのではなく、主に「戻ってくる波どうし」を干渉で弱めます。

STEP 1屈折率差がある界面では、電場の境界条件により反射が生じる
STEP 2膜の上面・下面から戻る波に、光路差と反射位相差が生じる
STEP 3膜厚と屈折率を選び、対象波長で逆位相・等振幅に近づける
STEP 4多層化して波長帯・角度・偏光・色・製造誤差まで最適化する

01光は電場と磁場の波

基礎

この章の着眼点 干渉で足す量と、最後に求める量は？

光は時間と空間の中を進む電磁波です。光学薄膜では、磁場を毎回追う代わりに主に電場 E の振幅と位相を追跡します。観測器が測る明るさは電場そのものではなく、時間平均された強度です。

E(z,t)=Re⁡ ⁣{E0exp⁡[i(kz−ωt+φ)]}E(z,t)=\operatorname{Re}\!\left\{E_0\exp[i(kz-\omega t+\varphi)]\right\}E(z,t)=Re{E0​exp[i(kz−ωt+φ)]}
E₀：振幅、k = 2π/λ：波数、ω = 2πf：角周波数、φ：初期位相。複素数は「大きさ＋位相」を一つにまとめる計算道具です。

振幅と強度は別物

干渉で足すのは電場振幅です。最後に絶対値の二乗を取り、強度に変換します。

I∝∣E∣2I\propto |E|^2I∝∣E∣2
振幅が2倍なら、強度は4倍。

屈折率とは

透明媒質中では位相速度が遅くなり、波長が短くなります。周波数は界面を越えても同じです。

n=cvλmedium=λvacn\begin{gathered}n=\frac{c}{v}\\[4pt]\lambda_{\mathrm{medium}}=\frac{\lambda_{\mathrm{vac}}}{n}\end{gathered}n=vc​λmedium​=nλvac​​​
n：屈折率、c：真空中の光速、v：媒質中の位相速度。

図は横にスクロールできます。拡大表示でも確認できます。

同じ波長でも山・谷の位置がずれていれば位相が違います。山と山は強め合い、山と谷は弱め合います。

複素電場が便利な理由実数の正弦波を毎回展開せず、反射・伝搬による「振幅倍率」と「位相回転」を掛け算で扱えます。薄膜計算の特性行列法もこの考え方の延長です。

振幅と強度の対応

振幅 1倍強度 1倍
振幅 2倍強度 4倍

強度は電場振幅の絶対値の二乗に比例します。

まとめを見る前に思い出す 干渉で足す量と、最後に求める量は？

この章のまとめ
  • 干渉では電場振幅を足し、強度は絶対値の二乗から求める。
  • 屈折率が高い媒質では位相速度と波長が小さくなる。
  • 複素電場は振幅と位相をまとめて扱う計算道具。

02なぜ透明なガラスでも反射するのか

最重要

この章の着眼点 反射係数の負符号は、何を表す？

界面の両側で屈折率が違うと、電場と磁場が満たすべき境界条件が変わります。入射波だけでは条件を同時に満たせないため、一部が反射波、残りが透過波になります。これがフレネル反射です。

r=n0−nsn0+nsR=∣r∣2\begin{gathered}r=\frac{n_0-n_s}{n_0+n_s}\\[4pt]R=|r|^2\end{gathered}r=n0​+ns​n0​−ns​​R=∣r∣2​
垂直入射・非吸収媒質の電場反射係数 r と反射率 R。r の符号は位相、|r|² は反射エネルギー比を表します。
EXAMPLE

空気 → ガラス（n = 1.52）

R=(1.00−1.521.00+1.52)2=0.0426R=\left(\frac{1.00-1.52}{1.00+1.52}\right)^2=0.0426R=(1.00+1.521.00−1.52​)2=0.0426。したがって片面で約4.26%反射します。平板の両面を考えると反射・多重反射が増えるため、測定値は「どの面を含めたか」に注意が必要です。

反射係数の「マイナス」は暗いという意味ではない

低屈折率側から高屈折率側へ反射すると r は負です。これは電場の山が谷へ反転する、すなわちπ rad（180°）の位相反転を表します。検出器が単独の反射光だけを見ると符号は見えませんが、別の波と重ねると干渉結果を左右します。

低 n → 高 n で反射電場は位相が π 反転します。
高 n → 低 n で反射電場は位相反転しません。

斜め入射では s と p に分かれる

入射面に対して電場が垂直な成分が s偏光、平行な成分が p偏光です。斜入射では両者のフレネル係数が異なり、p偏光はブリュースター角で界面反射が0になります（理想的な非吸収・単一界面）。

n0sin⁡θ0=n1sin⁡θ1tan⁡θB=n1n0\begin{gathered}n_0\sin\theta_0=n_1\sin\theta_1\\[4pt]\tan\theta_B=\frac{n_1}{n_0}\end{gathered}n0​sinθ0​=n1​sinθ1​tanθB​=n0​n1​​​
前者はスネルの法則、後者はブリュースター角。多層膜では各層内角と s/p の光学アドミタンスを別々に扱います。

まとめを見る前に思い出す 反射係数の負符号は、何を表す？

この章のまとめ
  • 界面の屈折率差と境界条件から反射が生じる。
  • 電場反射係数 r の符号は位相、反射率 R はエネルギー比を示す。
  • 斜入射では s偏光とp偏光を分けて考える。

03薄膜干渉で反射を打ち消す

最重要

この章の着眼点 位相が逆でも反射が残るのは、どんなとき？

膜を1層置くと、主に「膜の上面で反射した波」と「膜内を往復して下面で反射した波」が空気側へ戻ります。両者の位相差がπ、かつ振幅が等しいなら、電場の和は0になります。

位相と振幅を、分けて見る

青実線と茶破線：足し合わせる電場。下段の濃紺実線：その和。波形は概念図です。

同位相

山と山が重なる

逆位相・等振幅

振幅が等しければ打ち消す

逆位相・振幅が違う

差が残り、完全には消えない

図は横にスクロールできます。拡大表示でも確認できます。

図は経路を見やすくずらしています。実際の垂直入射では同じ軸上を進みます。

位相条件：光学膜厚を λ/4 にする

垂直入射で膜内を往復する光路長は 2n1d2n_1d2n1​d。これが真空波長の半分なら、伝搬だけで位相差πがつきます。

2n1d=λ02n1d=λ04d=λ04n1\begin{aligned}2n_1d&=\frac{\lambda_0}{2}\\[4pt]n_1d&=\frac{\lambda_0}{4}\\[4pt]d&=\frac{\lambda_0}{4n_1}\end{aligned}2n1​dn1​dd​=2λ0​​=4λ0​​=4n1​λ0​​​
n₁d を光学膜厚（optical thickness）と呼びます。d は物理膜厚です。

振幅条件：屈折率を幾何平均にする

位相だけ逆でも、一方が強ければ反射は残ります。垂直入射・非吸収・λ/4膜では、理想的な振幅一致条件は次式です。

n1=n0nsn_1=\sqrt{n_0n_s}n1​=n0​ns​​
空気 n₀ = 1、ガラス nₛ = 1.52 なら理想膜は n₁ ≈ 1.233。緻密な均一膜として使える材料が少ないため、単層には限界があります。
よくある誤解：「光路差がλ/2なら必ず消える」正しくは、伝搬位相に加えて各界面での反射位相も数え、さらに電場振幅も揃える必要があります。たとえば両界面とも低 n → 高 n なら双方がπ反転するため、反射位相差は相殺され、膜内伝搬のπが打消し条件を作ります。

まとめを見る前に思い出す 位相が逆でも反射が残るのは、どんなとき？

この章のまとめ
  • 打消しには逆位相に加え、振幅の一致が必要。
  • 垂直入射のλ/4膜は、膜内往復で伝搬位相差πをつくる。
  • 伝搬位相だけでなく、界面での反射位相も数える。

05多層膜は何を増やしているのか

設計

この章の着眼点 多層化で増える自由度と、増える負担は？

単層の自由度は実質「材料の n」と「膜厚 d」だけです。多層化すると各層の n・d が設計変数となり、複数波長・広帯域・斜入射・色・製造誤差を同時に整えられます。一方で、界面数、応力、吸収、膜厚誤差も増えます。

特性行列法：各層の変化を順番に掛ける

各層を通るとき、電場と磁場の関係は位相膜厚 δ と光学アドミタンス η で変わります。各層の2×2行列を入射順に掛ければ、全積層を一つの等価な界面として扱えます。

垂直入射では η ≈ n。斜入射では s と p で η の形が異なるため、別々に計算します。全体行列 M = M₁M₂…Mₙ から反射係数を求めます。

直感：アドミタンス整合

光から見た「伝わりやすさ」を空気側から基材側へ滑らかにつなぐと反射が減ります。低 n と高 n の層は、実効的なアドミタンスを波長ごとに回転・変換する部品として働きます。

直感：複数の反射波のベクトル和

各界面から戻る複素電場を、複素平面上の矢印として足します。対象波長で合計ベクトルが原点近くに来るよう各層厚を選びます。

06角度・偏光・反射色が変わる理由

重要

この章の着眼点 斜めで反射谷や色が変わる理由を説明できる？

斜めから見ると、層内の進行方向と界面法線の関係が変わります。位相膜厚に cos⁡θj\cos\theta_jcosθj​ が入るため、同じ物理膜厚でも干渉条件が短波長側へ移動します。一般にARの反射谷はブルーシフトします。

λmin⁡(θ0)≈λmin⁡(0)×1−(n0sin⁡θ0n1)2\begin{aligned}\lambda_{\min}(\theta_0)&\approx\lambda_{\min}(0)\\[-2pt]&\quad\times\sqrt{1-\left(\frac{n_0\sin\theta_0}{n_1}\right)^2}\end{aligned}λmin​(θ0​)​≈λmin​(0)×1−(n1​n0​sinθ0​​)2​​
単層の概算。θ₀は外部入射角、θ₁はスネルの法則で決まる膜内角。多層膜では各層が異なる角度を持つため行列計算が必要です。
ANGLE ESTIMATOR

単層ARの反射谷シフト（概算）

外部角を変えたとき、反射谷がどちらへ動くか予測してから確認しましょう。計算機は入射媒質を空気（n₀ = 1）として扱います。

概算した反射谷—

s偏光

反射色が生まれる仕組み

可視域の全波長を均等に反射すれば無彩色ですが、AR膜は波長ごとに反射率が違います。ある帯域だけ反射が残れば、そのスペクトルが照明の分光分布と人の等色関数で重み付けされ、色として知覚されます。

反射色=R(λ,θ,pol)×光源 S(λ)×人の色感度\begin{aligned}\text{反射色}&=R(\lambda,\theta,\mathrm{pol})\\&\quad\times\text{光源}\ S(\lambda)\\&\quad\times\text{人の色感度}\end{aligned}反射色​=R(λ,θ,pol)×光源 S(λ)×人の色感度​
同じ膜でも、照明・観察角・偏光・背景が変わると色は変わります。色設計では L*a*b* や色差 ΔE、角度ごとの軌跡を評価します。
角度色を抑えるとは単に垂直入射の反射率を下げることではありません。複数角度でスペクトル形状が大きく変わらない、s/pの分離が小さい、残留反射色の色度移動が小さい設計を探します。屈折率コントラスト、各層の位相膜厚、終端層、基材/HCの n が効きます。

まとめを見る前に思い出す 斜めで反射谷や色が変わる理由を説明できる？

この章のまとめ

  • s偏光とp偏光では、斜入射の反射特性が異なる。
  • 反射色はスペクトル・光源・人の色感度で決まる。

07実際の膜：吸収・散乱・粗さ

現実系

この章の着眼点 透過率の低下を、反射だけで説明してよい？

理想計算は「平坦・均一・非吸収」の膜を仮定しがちですが、実膜では吸収と散乱が加わります。透過率が下がったとき、すべてを反射増加と解釈してはいけません。

n~=n+ikR+T+A=1\begin{gathered}\widetilde n=n+ik\\[4pt]R+T+A=1\end{gathered}n=n+ikR+T+A=1​
ここでは exp[i(kz−ωt)] の時間規約を使用。ñ：複素屈折率、n：位相を決める実部、k：消衰係数。Aは吸収。散乱を分離する場合は R + T + A + S = 1 と考えると診断しやすい。

吸収

酸素欠損、金属残留、有機のUV吸収など。透過率低下、色付き、k増加として現れます。

散乱

粒子凝集、結晶粒、ボイド、表面凹凸。ヘイズ、角度分布の広がり、白っぽさにつながります。

不均一

膜厚・nの面内/深さ方向変動。分光谷の幅広化、位置ばらつき、筋・色ムラになります。

粗さが小さければ無視できるか

粗さ振幅が波長より十分小さければ散乱は弱くなりますが、界面粗さは「実効的な遷移層」として干渉位相にも影響します。また、周期性のある筋はRMS粗さが小さくても回折・方向性散乱を生むことがあります。AFM値ひとつで外観を決めつけず、空間周波数と観察条件を合わせて考えます。

まとめを見る前に思い出す 透過率の低下を、反射だけで説明してよい？

この章のまとめ
  • 実膜では反射・透過に加え、吸収や散乱を考える。
  • 凝集・凹凸・不均一は、ヘイズや筋・色ムラにつながる。
  • 粗さの大きさだけでなく、空間周波数と観察条件を確認する。

11実務的な設計・開発フロー

統合

この章の着眼点 最低反射率だけでは、量産設計として何が足りない？

  1. 要求を数値化する
    波長域、平均/最大反射率、透過率、入射角、偏光、反射色、基材、耐久、コスト、タクトを定義。
  2. 実積層をモデル化する
    空気/機能層/HC/基材/粘着/他部材を並べ、各層の n(λ), k(λ), d を入れる。コヒーレント/インコヒーレント層を区別。

    材料と膜厚範囲を制約し、波長・角度・偏光の目的関数を最小化。複数初期値で局所解を比較。

    各材料を単層で成膜し、分光・エリプソで実プロセスの n/k/レートを取得。設計DBを更新。
  7. 試作→残差解析

問3｜位相が逆なら、なぜ反射率が必ず0にならないのか？
打ち消しには位相差πに加えて、二つの反射波の電場振幅が等しいことが必要です。振幅が違えば差分が残り、その絶対値二乗が残留反射率になります。

問5｜透過率だけが低下したとき、膜厚ずれと断定できない理由は？
吸収 k の増加や散乱でも透過率は低下します。反射・透過・ヘイズ/散乱を合わせ、エネルギー収支で切り分ける必要があります。
