# セラミックス材料工学 中級者向け教科書
## ChatGPT Work用・完全構成設計書 v1.0

---

## 0. このファイルの目的

本ファイルは、ChatGPT Work等を用いて**「セラミックス材料工学の中級者向け教科書」**を作成するための構成設計書である。

単なる用語集や概要説明ではなく、材料R&D・プロセス開発・品質解析・製造技術の実務に接続できるレベルを目標とする。

教科書全体では、以下の因果関係を一貫して追う。

**組成 → 原子・電子構造 → 化学結合 → 結晶構造 → 欠陥 → 相平衡 → 粉体 → 分散 → 成形 → 脱脂 → 焼結 → 微構造 → 物性 → 評価 → 不良 → 材料設計 → 量産**

---

# 1. 想定読者

- セラミックス分野に新しく配属された材料・化学系技術者
- 無機材料、薄膜、コーティング、電子材料などの経験を持ち、バルクセラミックスまで理解を広げたい技術者
- セラミックスメーカーのR&D、プロセス開発、生産技術、品質保証担当者
- 大学材料工学の基礎を実務レベルへ引き上げたい人
- 「なぜその物性になるのか」「なぜその条件で不良になるのか」を説明できるようになりたい人

---

# 2. 到達目標

教科書を一通り学習した読者が、以下を自分の言葉で説明できることを目標とする。

1. セラミックスと金属・高分子の本質的な違い
2. 原子結合と物性の関係
3. 結晶構造・欠陥・粒界が物性へ与える影響
4. 相図から材料の安定相を判断する考え方
5. 粉体・スラリー・成形条件が焼結体へ与える影響
6. 焼結の駆動力と主要な物質移動機構
7. 微構造と機械・熱・電気・光学特性の関係
8. XRD、SEM、XPS等の分析結果を材料現象へ結びつける方法
9. クラック、反り、気孔、異常粒成長などの不良原因を整理する方法
10. 組成・プロセス・微構造・物性をつないだ材料設計
11. 研究条件を量産条件へ移行する際の考え方
12. セラミックス材料について技術者同士で議論できるレベルの語彙と論理

# 62. 最終到達イメージ

この教科書を完了した読者は、例えば次の問いに対して体系的に回答できる状態を目指す。

- なぜセラミックスは硬いのに割れやすいのか。
- なぜ粉体粒径を小さくすると焼結しやすくなるのか。
- なぜ凝集が残ると焼結後の強度が低下するのか。
- なぜ焼結温度を上げすぎると性能が悪化する場合があるのか。
- なぜ気孔は強度・熱伝導・透明性を低下させるのか。
- なぜZrO2は他のセラミックスより破壊靭性を高くできるのか。
- なぜBaTiO3は高い誘電率を示すのか。
- なぜ酸素欠損によって電気・光学特性が変化するのか。
- XRDピークがシフトした場合、何を疑うべきか。
- SEMで気孔を見つけた場合、どの前工程まで遡るべきか。
- 強度ばらつきが大きい場合、材料平均値だけを見てはいけないのはなぜか。
- 原料、プロセス、微構造、物性をどのようにつないで研究計画を立てるか。

これらを「用語の暗記」ではなく、材料科学の因果関係として説明できることを最終目標とする。
