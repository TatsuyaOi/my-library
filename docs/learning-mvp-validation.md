# 学習教材MVP 検証記録

検証日：2026-09-19。対象は新規教材生成・一覧接続・公開境界。

## 構成判断

- 既存の9カテゴリ、30件の公開索引、トップページ、資料URLを維持。
- 新教材はカテゴリーに依存しない `content/<slug>/index.html` を生成。
- サイト版を標準とし、試験教材は `draft` / `publish: false`。
- 新規教材のメタ情報は既存のHTMLメタ情報・Inboxスキーマと分離。
- サイトの公開範囲はGitHub APIでpublicと確認。試験教材は公開資料と説明用の例のみで作成。

## 実施済み

- unittest 48件中47件成功、1件スキップ。スキップは既存のシンボリックリンク作成テスト（このWindows環境では利用不可）。
- 公開用30件、下書きプレビュー31件を生成。公開用に試験教材の本文・画像がないことを検査。
- 公開可否の型、下書き公開の拒否、公開後の取り下げ、slugとフォルダ一致、カテゴリ、日付、二件目の一覧追加を回帰テスト。
- 画像欠落、大文字小文字不一致、存在しないアンカーの拒否を確認。
- 失敗時の既存プレビュー保持と、テスト環境での再生成バイト一致を確認。
- 実リポジトリでも2回生成し、公開用とプレビューの全414ファイルがバイト一致した。
- 360、390、768、1280pxのブラウザ表示で全体の横はみ出しなし。表は必要な幅だけ局所横スクロール。図のロード成功。
- 390pxと1280pxの画面を目視確認。トップ検索、カテゴリ一覧、教材リンク、Enterでの目次展開、章への移動が成功。
- 例題の 40 × 0.5 / 1.0 = 20、圧力3倍で平均自由行程1/3を検算。
- 出典3ページの本文を読み、教材の該当説明と対応させた。

## 未実施・制約

- 200%拡大：ブラウザのショートカットでは倍率変更を確認できず未検証。
- 印刷：専用CSSは実装したが、印刷プレビュー・実機印刷は未検証。
- Android実機では未検証。上記はブラウザの表示幅による確認。
- 単一HTML・オフライン動作、コース生成、クイズ自動採点はMVP対象外。
- 本記録はローカル検証。GitHub Actionsの結果はPR側で確認する。マージとデプロイは実施しない。

## ローカル生成時の障害

既存のOneDrive配下 `_site` の置換がアクセス制限で部分停止した。
自動承認レビューは再解析ポイントの範囲が不明として削除を一度拒否した。
読み取り検査でリンク先・シンボリックリンク・範囲外解決先がないことを確認した後、
承認された生成物の再作成でビルドが成功した。その後の再生成でOneDriveの読取専用ディレクトリ属性が原因と判明したため、生成先の範囲・リンクを検査したうえで読取専用属性を解除して再試行する処理を追加し、Windows用回帰テストを通した。原本は変更・削除していない。
