# 資料の分類と移動（2026-09-20）

## 置き場の基準

- `71_勉強`：原理・概念・技術を学ぶ教材、比較学習、心理学、資格・学習計画。
- `51_仕事`：業界分析、市場動向、事業評価、業務の意思決定に使うレポート。
- `41_AI`：AIに特化した活用・事業計画・ニュース。既存の専門カテゴリとして維持。
- `21_基本情報`・`22_簿記`・`11_哲学`：既存の専門カテゴリとして維持。
- `99_その他`：上記に属さない資料。現在はLyrics Companionの運用引継ぎ。

技術分野の資料でも、学ぶことが主目的なら勉強、業界・市場・事業を判断することが主目的なら仕事へ置く。
心理学の教材は、会話の記録と区別して勉強へ置く。ローカルの未登録フォルダはこの整理で公開対象に加えていない。

## 旧URLと復習の互換性

`library-moves.json` が移動対応表。`prepare_pages.py` は、新しい保存先が公開索引にある場合に限り、
公開出力済みの資料フォルダを旧URLへもコピーする。旧HTMLの章アンカー、画像、原本ダウンロードを維持し、
旧パスを索引へ重複掲載しない。リポジトリ内の旧資料フォルダに編集用コピーは残さない。
公開索引から取り下げた資料の旧URLは、次の公開出力から除外される。
対応表は連鎖させない。将来さらに移動するときは、旧URLの最終保存先を明示して検証する。

復習はlesson_id・question_id・revision・解答・台帳を維持し、分類と根拠パスだけを更新した。
参照先が変わった問題データは新しい不変JSONとして保存し、旧版を保持する。
原文バイトと抽出本文・アンカーの一致を確認し、品質記録にパス移行を記録した。
新しい問題の生成や再採点、端末内の学習履歴の変更は行っていない。

公開内容の変更はPRのマージ後。ローカルのフォルダ移動だけではPagesの表示は変わらない。
